# Ассистент по питанию — личный Telegram-бот

## Что умеет
- Показывает план на сегодня и на неделю: время, блюда, КБЖУ, отметки ✅/⏭/🔄.
- Считает итоги дня: съедено / цель / осталось по КБЖУ и клетчатке.
- Записывает еду обычным текстом («съел 200 г гречки»), КБЖУ оценивает ИИ.
- Отмечает приёмы по плану кнопками и командами `/ate`, `/skip`.
- Собирает список покупок из плана на 7 дней (или на N).
- Хранит избранные блюда и вес, показывает динамику веса.
- Напоминает о приёме пищи за 10 минут, присылает вечерний итог и недельный отчёт.
- Каждый понедельник копирует план с прошлой недели; новый план составляет ИИ по просьбе.
- Запоминает новые предпочтения («не люблю творог») и правит план по просьбе.

## Как пользоваться
Кнопки: **📅 Сегодня · 📊 Итоги · 🗓 Неделя · 🛒 Покупки**.

Команды:
| Команда | Что делает |
|---|---|
| `/day пт` | план на день |
| `/ate завтрак`, `/skip обед` | отметить приём по плану |
| `/del 3` | удалить запись №3 из «Итогов» |
| `/shop 3` | покупки на 3 дня |
| `/fav`, `/fav 2` | избранное / записать избранное №2 |
| `/w 78.4`, `/weight` | записать вес / динамика |
| `/remind on\|off\|15` | напоминания вкл/выкл / за сколько минут |
| `/evening 22:00` | время вечернего итога |
| `/tz Europe/Moscow` | часовой пояс |
| `/profile`, `/reseed`, `/export`, `/usage`, `/help` | профиль, перезагрузка seed, CSV дневника, расход ИИ, справка |

Примеры обычных сообщений:
- «съел 200 г гречки и куриную грудку»
- «вместо обеда съел шаурму»
- «что поесть вечером?»
- «я в ресторане: цезарь, паста карбонара, стейк — что выбрать?»
- «не люблю творог», «тренировки теперь по вечерам»
- «поменяй завтраки в будни на что-то быстрое»
- «составь план на следующую неделю» → бот опишет план и спросит «Сохранить?» → «да»
- «сохрани это в избранное», «удали последнюю запись», «как я ел на этой неделе?»

## Как поднять
1. Создать бота в [@BotFather](https://t.me/BotFather) → получить токен.
2. Узнать свой Telegram ID в [@userinfobot](https://t.me/userinfobot).
3. Получить ключ Anthropic на [console.anthropic.com](https://console.anthropic.com).
4. Скопировать папку проекта на сервер (Ubuntu/Debian).
5. Запустить `./deploy.sh` — поставит Docker и создаст `.env`.
6. Заполнить `.env` (токен, ключ, ID, пароль БД).
7. Снова `./deploy.sh` — бот запущен.

## Как поменять начальные данные
Отредактировать файлы в `seed/` (`profile.md`, `targets.json`, `plan.json`) и написать боту `/reseed`. Профиль, цели и план текущей недели заменятся, дневник останется.

## Обслуживание
```bash
./deploy.sh            # обновить (git pull) и перезапустить
./deploy.sh logs       # логи бота
./deploy.sh restart    # перезапуск
./deploy.sh stop       # остановить (данные сохраняются)
./deploy.sh backup     # бэкап БД сейчас
./deploy.sh restore backups/db_2026-10-10_0300.sql.gz   # восстановить
```
Автобэкап — раз в сутки в `./backups`, хранятся 14 последних.

## Как устроено
- `app/main.py` при старте применяет миграции Alembic, при пустой БД грузит `seed/`, запускает бота (long polling) и планировщик.
- Планировщик раз в минуту проверяет, что пора отправить (напоминание, итог, отчёт). Отправленное записывается в БД, поэтому после рестарта ничего не дублируется.
- `services.py` — вся логика без ИИ (план, итоги, покупки, напоминания, отчёты); `repo.py` — запросы к PostgreSQL.
- `ai.py` — агент: короткий кэшируемый промпт, 9 инструментов, не больше 4 запросов на сообщение. Суммы КБЖУ и проверки делает код.

## Где тратятся токены
ИИ вызывается только на обычные текстовые сообщения. Кнопки, команды, напоминания и отчёты работают без него.
На каждое сообщение уходит 1–4 запроса: статичный промпт с описанием инструментов берётся из кэша (в 10 раз дешевле), полной цены стоят только контекст дня и ответ. План недели ИИ запрашивает, только когда нужно его править или составлять заново. Обычный ответ ограничен 600 токенами, генерация недельного плана — 4000.
Сколько потрачено токенов и долларов сегодня и за месяц — команда `/usage`. Цены по умолчанию — для Claude Sonnet 5.5, их можно поменять в `.env` (`PRICE_INPUT`, `PRICE_OUTPUT`, `PRICE_CACHE_READ`, `PRICE_CACHE_WRITE`, $ за 1 млн токенов).
